# Angular UI Component Library

A reusable Angular UI component library built with **Angular 19+**.  
Includes 20+ standalone, fully documented components (Button, Accordion, Dropdown, Table, Dialog, Form Controls, etc.).  
All components are documented with **Compodoc** and can be easily integrated into Angular projects.

---

## 🚀 Features

- ✅ 20+ UI Components (form controls, navigation, feedback, data display)  
- ✅ Standalone Angular components (no `NgModule` boilerplate)  
- ✅ **Reactive Forms** compatible (CVA implemented for inputs, checkboxes, switches, etc.)  
- ✅ Built-in **Compodoc documentation** (`npm run docs`)  
- ✅ Ready for theming and customization with SCSS variables  
- ✅ Portable → can be published as an **npm package**
