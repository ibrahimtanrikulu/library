Button

Interactive

Buttons trigger an action. Variants follow shadcn/ui semantics (default, outline, destructive, ghost, link). Use button--icon for icon-only buttons and pass a Font Awesome class via icon.

  • When to use: Primary actions, form submit, icon-only actions.
  • Features: Keyboard focus ring, disabled state, size presets (sm, lg), icon spacing.
  • Accessibility: Real <button> elements; labels are required for non-icon usage.

Input • Number • Password

Forms

Floating-label inputs styled with the same token palette. Keep labels short and meaningful. Numbers enforce min/max; password input hides the value.

  • Features: Floating label, focus ring, disabled state, consistent spacing.
  • Accessibility: Labels are linked via for/id; placeholder is not the label.

Textarea

Forms

Multi-line text input with floating label and matching focus treatment.

Dropdown

Selection

Headless dropdown supporting single or multiple selection and optional search. Provide [data] items; listen to (selectedList).

  • Single vs Multi: Set [multiStatus] to true for multi-select.
  • Filtering: Enable inline search with [searchStatus]="true".

Checkbox

Forms

Accessible checkbox with label and consistent sizing across the library.

Switch
